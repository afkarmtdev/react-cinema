Design exploration · 9 Sep 2026 · Cinema, Paperback, and Vice City are in the app

Six looks for CineReact

The same two screens, Library and Entry detail, redrawn in six palettes. Each one is a full token set in the shape of src/theme/index.ts, so any of them can drop in. Cinema, Paperback, and Vice City now ship in the app and can be picked under Settings on the Me screen. Teh Tarik, Noir, and Marquee remain candidates; each is one ThemeColors object away.

How themes work in the code now
  • ThemeContext holds the choice; every screen builds its styles through useThemedStyles(makeStyles) from the active ThemeColors. The picker sits under Settings on the Me screen and is saved on the device.
  • Adding one of the remaining three means adding its token object to src/theme/index.ts, listing it in THEME_NAMES, and adding its name string in English and Malay.
  • Paperback is the only light theme. A System option that follows the phone would pair it with Cinema; not built yet.
  • Vice City and Marquee carry a second accent (cyan, blue) in the secondary slot, used for the active tab. The other themes set it equal to primary. The sunset hero gradient is not in the app; it would need expo-linear-gradient.
  • Covers in the mockup are gradients built from each theme's own colours. Real covers are whatever image link you paste, so a theme lives mostly in the chrome around them.
